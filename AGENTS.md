# Repository working conventions

Keep the scientific model, exact claims, proofs, and consequential scope in topic-based
science/ files. Each result has one authoritative home. Preserve the MIT license.
Use GitHub-native fenced math blocks and protected inline math; avoid display math
inside tables. Maintain local links and the connected reading route.

Preserve mean-energy rather than peak-energy quantifiers. Do not identify a coarse
helper record with the full complementary channel. Keep the counting baseline
number-diagonal before classical postprocessing, and keep endpoint coding unrestricted.
Credit the collective optical capacity to the partial-monitoring analysis and retain
primary-source attribution for assistance and coding.

Run python verification/verify.py after scientific changes. Expected outputs are
reference data, not a file to refresh automatically when a test fails. Finite tests
are not an arbitrary-dimensional or asymptotic proof certificate. Keep personal
coaching, exploration history, venue planning, and unpublished manuscript artifacts
out of the public tree. Educational furnishing follows the owner's selected single
anchor; do not infer a choice from a recommendation.
